**项目介绍：**

**个人职责：**

**1、Bot 对话与会话记忆模块：**

- **统一对话链路：** 以 ChatClient 为统一入口，通过 Advisor 责任链组合会话记忆、RAG 检索和审计能力；根据 Bot 配置动态选择 ChatModel，实现多模型可切换。
- **记忆与历史分离：** 通过 MessageChatMemoryAdvisor 注入最近消息窗口，完整聊天记录独立落 MySQL，避免上下文无限膨胀带来的 Token 成本与延迟问题。
- **流式输出：** 基于 WebFlux + SSE 返回文本、引用、工具状态等事件，阻塞型调用（JDBC、MyBatis-Plus）切换到受控 Scheduler，避免占用 EventLoop。

**2、RAG 知识库与混合检索模块：**

- **异步入库：** 文档上传后写任务表，通过 RocketMQ 异步完成 Tika 解析、Token 切片与向量化，Chunk 同时写入 Milvus 和 Elasticsearch，MySQL 作为任务事实源、双索引可重建。
- **双路召回与重排：** 查询时向量检索与 BM25 并行召回，按 Chunk ID 去重后经 RRF 融合和 Rerank 二次排序注入 Prompt；单路超时自动降级到另一路，不放大故障。
- **权限前置：** 知识权限（ACL）进入 Milvus Metadata Filter 与 ES Filter 检索条件，注入 Prompt 前再做一次业务校验，双保险防越权引用。

**3、Tool Calling 与 MCP 工具接入模块：**

- **工具统一治理：** 将内部 Java 方法（@Tool）、动态 HTTP 接口和外部 MCP 工具统一适配为 ToolCallback，按 Bot 建立工具白名单；通过 MCP Client Starter 接入标准 MCP Server。
- **安全与审计：** ToolContext 由服务端注入租户与用户上下文，不信任模型生成的身份参数；写操作工具要求幂等键与二次确认，执行日志记录 traceId、耗时与结果，便于审计回溯。
