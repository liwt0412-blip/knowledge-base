# 成飞过渡期 · 双线备战行动表

> 背景：2026-09 入职成飞外包（神州数码驻场，成都），中高级开发，税前 20K，合同期至 2027-09。
> 目的：把「2027-03 前后拿 25K+」从一个念头，拆成可验证的产出物。
> 原则：每项动作必须有产出物和验收标准，不写「继续学习」。
> 上一版（三线并行 / 一年合同）已归档，见 [[🎯 职业规划/归档/成飞合同期-三线并行季度检查表-归档-20260923|旧版检查表]]。

---

## 三个事实前提

1. **决定跳槽成败的不是简历，是「能不能讲透」**——面试追问三层就见底。所以本表的中心是「把工作吃成素材」，不是「刷面试题」。
2. **2027-03 是新机会窗口，不是合同到期日。** 合同 2027-09 才到期，提前走需先核对服务期/违约金条款。
3. **学历（统招大专 + 成人本科）在简历初筛是减法。** 路径只能是内推 / 猎头 / 垂直 AI 岗，海投不作为主力。详见 [[🎯 职业规划/就业线选择复盘-2026-09|就业线选择复盘]]。

## 时间轴（2026-10 ~ 2027-03，共 6 个月）

### P1 · 稳交付 + 定模块（2026-10 ~ 11）

| 动作 | 验收标准 |
|---|---|
| 现场交付兜住：把上级交接的职责跑顺，不出事故 | 无因本人责任导致的交付事故 |
| 从工作里选定 2–3 个深挖模块（候选：跨语言 AI 任务流转 / 长任务可靠性 / LLM 输出治理） | 写下模块清单 + 每个模块要回答的四个问题 → 载体：[[🖥 项目笔记/SZSM本体平台/深挖模块工作台\|深挖模块工作台]] |
| 查清合同的服务期 / 违约金条款 | 明确「2027-03 走」的代价（钱 / 流程 / 影响） |
| 摸清「神州内部岗」的真实性（见下方观察项） | 2026-12 前拿到具体条件，或判定为画饼 |

### P2 · 吃透 + 成型（2026-12 ~ 2027-01）

| 动作 | 验收标准 |
|---|---|
| 每个深挖模块能讲四层：问题 / 设计 / 取舍 / 验证 | 对着录音讲 10 分钟不卡壳 |
| 简历草稿（石化 + AskXBOT + 成飞；成飞按外包口径） | 一页版成型 |
| 搭内推渠道：进 2–3 个 AI 社群 / 开源社区，认识 5 个能内推的人 | 有具体联系人，不是「关注了公众号」 |
| 市场温度测试：投 3–5 家试水 | 拿到真实反馈，知道自己现在值多少 |

### P3 · 投递 + 决策（2027-02 ~ 03）

| 动作 | 验收标准 |
|---|---|
| 集中投递，内推优先 | 拿到 ≥ 3 个面试 |
| 每轮面试后复盘被追问穿的点并补齐 | 每轮有书面复盘记录 |
| 决策：拿到 offer / 谈内部转岗 / 留下 | 明确选择并写下理由，不裸奔 |

## 观察项 · 神州内部岗（不是方向）

**事实**：成飞现场负责人提到「有机会进入神州内部岗位」，未给出任何具体条件。

**处理规则**：

- 时限：2026-12 前问出具体条件——什么岗位、什么时候、什么薪资、谁审批。
- 判定：拿不到具体条件 → 按画饼处理，不再投入注意力。
- 反直觉提醒：**外包薪资常高于同级正式岗**（外包把社保福利折算成了现金）。转内部岗可能降薪，要先把账算清再动心。
- 它只进「观察项」，不进「方向」——方向需要有可控的路径，「有机会」不是路径。

---

## 冻结线 · 创业（寻一）的唤醒条件

创业线当前冻结（股份保留、不主动推进）。满足以下任一条件时重新评估：

- 出现可复制的获客渠道（不依赖熟人转介绍）
- 就业线出现重大变化（失业 / 合同不续 / 项目终止）
- 有合伙人全职投入

红线不变：不碰作弊产品的技术 / 推广 / 商业化。

## 提前离场信号（比 2027-03 更早的决策点）

- **交付环境恶化**（没活干 / 被边缘化 / 项目要停）→ 提前启动跳槽，不等窗口期
- **P2 末（2027-01）市场反馈低于 25K** → 降低预期或补短板，别硬冲，也别自我欺骗
- **交付压力挤掉全部备战时间** → 立即降级交付投入：做「合格」而不是「优秀」，保住备战
