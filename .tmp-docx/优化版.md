- Rerank 重排后 Top5 准确率从 76% 提升至 **91%**

**个人职责：**

**1、Bot 对话与会话记忆模块：**

- **统一对话链路：** 以 ChatClient 为统一入口，通过 Advisor 责任链组合会话记忆、RAG 检索和审计能力；根据 Bot 配置动态选择 ChatModel（Qwen / DeepSeek），实现多模型可切换与 fallback 降级链。
- **记忆与历史分离：** 通过 MessageChatMemoryAdvisor 注入最近 10 轮对话窗口（约 4K Token），完整聊天记录独立落 MySQL 支持无限回溯；对比"全量窗口注入"方案，Token 消耗降低约 55%，同时避免了长上下文导致的模型"迷失中间"问题。
- **流式输出：** 基于 WebFlux + SSE 返回文本、引用来源、工具调用状态等分类事件；阻塞型调用（JDBC、MyBatis-Plus）切换到受控 Scheduler 避免占用 EventLoop；用户断开连接后及时终止大模型调用，避免浪费 Token；平均首字延迟控制在 **2 秒以内**。

**2、RAG 知识库与混合检索模块：**

- **异步入库：** 文档上传后写任务表（MySQL 作为事实源），通过 RocketMQ 异步完成 Tika 解析、语义边界感知分块与向量化；Chunk 同时写入 Milvus 和 Elasticsearch 双索引，任务失败可重试、双索引可从事实源全量重建。
- **双路召回与重排：** 查询时向量检索（Milvus）与 BM25（ES）并行召回 Top50 → 按 Chunk ID 去重 → RRF 融合排序 → BGE-Reranker 交叉编码精排 Top5 → 注入 Prompt。单路超时自动降级到另一路，不放大故障。
- **评估体系：** 构建 200 条覆盖制度查询、业务操作、故障排查等典型场景的 Golden Dataset，基于 RAGAS 框架定期跑回归评估（Faithfulness、Answer Relevancy、Context Precision、Context Recall 四项指标），新版本上线前对比基线。Rerank 引入后 Context Precision 从 68% 提升至 87%，Answer Relevancy 从 72% 提升至 85%。
- **幻觉治理（全链路）：** 检索侧靠混合检索 + Rerank 保证上下文精准；生成侧 Prompt 强约束——"若检索文档无相关信息，直接回答'当前知识库未收录该内容'，禁止编造"；校验侧对输出做事实一致性检查 + 引用溯源；迭代侧建立 Bad Case 登记→根因分析→对照实验→数据验证的闭环机制，关键场景事实性幻觉率从 12% 降至 2% 以下。
- **权限前置：** 知识权限（ACL）进入 Milvus Metadata Filter 与 ES Filter 检索条件，注入 Prompt 前再做一次业务校验，双保险防越权引用。

**3、Tool Calling 与 MCP 工具接入模块：**

- **工具统一治理：** 将内部 Java 方法（`@Tool` 注解）、动态 HTTP 接口和外部 MCP 工具统一适配为 ToolCallback，按 Bot 建立工具白名单；通过 MCP Client Starter 接入标准 MCP Server。
- **安全与审计：** ToolContext 由服务端注入租户与用户上下文（不信任模型生成的身份参数）；写操作工具要求幂等键与二次确认；执行日志记录 traceId、toolName、耗时与结果，支持按 Bot + 时间范围的审计回溯。
- **Bad Case 驱动优化：** 早期版本模型调用工具时频繁传错参数名（如将 `deviceId` 写成 `device_id`），根因是工具描述与模型理解之间存在 gap——通过优化 `@Tool` 的 description（加入参数示例 + 边界说明）配合 Few-Shot Prompt，工具调用正确率从 82% 提升至 96%。

Spring Cloud Alibaba、SpringBoot、MyBatis-Plus、MySQL、Redis、MongoDB、RabbitMQ、Elasticsearch、Netty、WebSocket、XXL-Job、Nacos、Gateway、OSS

**项目介绍：**

基于地理位置的同城社交应用，主打"发现身边有趣的人和事"，支持图文/视频动态、兴趣圈子、线下活动报名、实时聊天和位置共享等功能，分为用户端（App/小程序）和管理端（内容审核、用户管理、数据统计）。用户规模约 5 万 DAU。

**个人职责：**

**1、附近的人模块：**

- 基于 Redis GEO 实现附近用户搜索与距离排序，位置 30 分钟未更新自动过期；热门城市按城市拆分 GEO Key 分片（北京/上海/广州各一个 Key），配合更新防抖（5 分钟内重复上报跳过）与 Caffeine 本地缓存扛住高频位置上报；支持隐藏位置、模糊距离等隐私保护策略。

**2、内容审核与信用体系模块：**

- 采用"先发后审"策略提升用户体验：内容发布后立即展示，同时发 MQ 异步调用第三方审核 API，违规内容自动下架并通知用户；配套用户信用分体系，按违规程度阶梯处罚（限发、禁言、封号），良好行为可恢复分数。

### 店堂主（WEIIT）数字零售 SaaS 系统　　2020.08 - 2021.07

**技术架构：**

Spring Cloud、OAuth2.0、Shiro、JWT、Gateway、Nacos、MyBatis、MySQL（Schema 隔离）、Redis、Nginx、Ant Design Vue

**项目介绍：**

面向中小企业的数字化零售 SaaS 系统，帮助企业一键生成独立品牌的小程序商城、公众号商城和 PC 商城，涵盖商品、订单、会员、营销、自定义装修、微信生态对接和支付等核心模块，支持多租户数据隔离。

**个人职责：**

**1、营销中心模块：**

- 实现拼团（Redis 记录参团人数、XXL-Job 扫描过期未成团自动退款）、优惠券（乐观锁防超发 + Redis 计数防重复领取）、积分（规则配置化、流水记录、余额缓存）等营销工具。

**2、微信生态对接模块：**

- 基于微信开放平台第三方平台能力，实现小程序一键授权、ext.json 配置注入、模板代码自动上传与批量升级；接管公众号菜单、素材与群发；token 加密存储并自动刷新。
