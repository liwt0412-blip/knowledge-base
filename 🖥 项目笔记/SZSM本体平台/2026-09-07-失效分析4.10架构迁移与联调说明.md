## 2. 架构迁移前后

| 位置 | 迁移前 | 迁移后 |
| --- | --- | --- |
| 管理页面 | 运行资产 → 业务入口绑定 | 领域管理 → 目标领域详情 → 流程 → 失效分析检索入口 |
| Web API/类型 | 旧 domainScene、runtime-assets 页面配套实现 | 独立 `businessEntryBinding` API/类型和 `FailureAnalysisRetrievalBinding.vue` |
| 入口解析 | 依赖 dev 已退役的 `BusinessEntryBindingResolver` | `OpenRetrievalScopeResolverImpl` 直接通过 Mapper 查询当前租户唯一启用的 `RETRIEVAL + FAILURE_ANALYSIS` 绑定 |
| 发布范围 | 4.10 需要保留发布冻结范围约束 | `DomainRetrievalRuntimeAssembler.assembleActive` 组装当前发布，`EvidenceAuthorityStore.resolveScope` 确认可访问范围 |
| 全文检索 | 迁移时需与 dev 检索能力对齐 | `OpenRetrievalDocumentSearchServiceImpl` 使用 `KnowledgeRetrievalFacade`，保留 4.10 响应投影 |
| HTTP 路由 | dev 的同路径 Controller 与三个 4.10 Controller 冲突 | 保留三个 `OpenRetrieval*Controller`；`DocumentRetrievalOpenApiController` 取消 Spring Controller 注册 |

范围解析链：

```text
三个 4.10 Controller
  → OpenRetrieval*Service
  → OpenRetrievalScopeResolverImpl
  → 当前租户唯一启用的 RETRIEVAL + FAILURE_ANALYSIS 绑定
  → DomainRetrievalRuntimeAssembler：当前活动发布
  → EvidenceAuthorityStore：发布权威范围
  → 清单/counts、同范围搜索、精确发布版本文件读取
```

全文搜索额外调用 `KnowledgeRetrievalFacade`；文件读取使用来源绑定的数据源及存储服务，不是所有操作都通过检索门面读取文件。

`DocumentRetrievalOpenApiController` 虽保留方法和 `@RequestMapping` 源码，但没有注册为 Spring Controller，不是另一套可调用的 HTTP 入口。它的方法级测试不等于这套路由已开放；以后收敛时必须先处理公开合同和重复映射。

零条或多条启用绑定均失败关闭；不随机选择领域。配置绑定不等于发布完成，场景、活动发布、检索资产及文件依赖仍须有效。

## 4. 应用方联调合同

基础地址及代理前缀由实际联调环境确定，不从本机端口推断部署地址。由失效分析后端调用本体平台。

```text
tenant-id: 1
X-User-Id: <业务操作人的正整数标识>
```

不传 Authorization/Token。`X-User-Id` 是声明的业务操作人，不是身份认证、不赋予 admin 权限，也不形成用户级文档 ACL；仅适用于已批准的受信内网边界。

| 接口 | 请求与参数 | 成功响应 |
| --- | --- | --- |
| 4.10.1 清单 | `GET /open-api/retrieval/v1/documents?source=REPORT&pageNo=1&pageSize=10`；文献改为 `PAPER` | `code=0,msg="查询成功"`，`data` 含双 counts、total、list |
| 4.10.2 搜索 | `POST /open-api/retrieval/v1/document-searches`；JSON 示例见下 | `code=0,msg="检索成功"`，含 returnedCount、list、纯文本 matchedText 和 matchRate |
| 4.10.3 文件 | `GET /open-api/retrieval/v1/documents/{documentId}/content?disposition=inline`；下载改为 `attachment` | 原始文件字节，不套 JSON |

```json
{"query":"检索词","source":"ALL","limit":10}
```

搜索 source 为 `ALL/REPORT/PAPER`，limit 为 1～20；清单 pageSize 为 1～200。`documentId` 使用清单/搜索返回值，不拼内部文件、数据源或发布坐标。空清单、空搜索结果仍返回相应成功文案。

文件支持 Range 和 ETag；4.10 不发送 Last-Modified，日期条件保守返回完整内容。浏览器直接打开 URL 无法自行添加上述请求头，应由应用后端转发文件请求和必要响应头，或采用带头请求方案，不把身份头塞入 URL。

| HTTP | 含义/处理 |
| --- | --- |
| 400 | 参数或调用头非法 |
| 403 | 租户或唯一启用绑定等访问条件不满足 |
| 404 | 文档不在当前可见范围，刷新清单 |
| 409 | 可见资料的文件内容不可读取 |
| 422 | 检索词不合法 |
| 503 | 发布或依赖不可用，不得当成“0 条资料” |
| 416 | Range 不合法，按文件响应处理 |

普通错误体为 `{code,msg,data:{errorType,details:[]}}`；416 不套该 JSON。文件流已提交后若中断，不追加 JSON，应由调用方检测不完整文件。

`contentAvailable` 的既有轻量判断未在本次迁移中改为逐文件对象存储探测，不应据此保证下一次文件请求必定成功。跨请求若发布切换，需重新读取清单或搜索结果。
